KrakenSQL is an open source (GPL licensed), database with a focus on, speed, simplicity and the open source community. KrakenSQL does not aim to replace existing database engines but simply, to take an approach that aims to keep things focused on a few important details.

This approach makes KrakenSQL a good alternative.

Speed

Where speed is the focus, we're focused on key features that are useful for modern applications.

Simplicity

Where simplicity matters, we're focused on keeping operational task as simple as possible and at the same time, well documented.

Open source community

The open source community has changed the industry through collaboration, innovation and accessibility. For this reason, KrakenSQL is GPL licensed and freely available on Github.
