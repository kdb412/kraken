KrakenDB: the world's alternative open source database

KrakenDB is an open source (GPL licensed), database with a focus on, speed, simplicity and the open source community. KrakenDB does not aim to replace existing database engines but simply, to take an approach that aims to keep things focused on a few important details. This approach makes KrakenDB a good alternative.

Speed

Where speed is the focus, we're focused on features that make it possible to quickly deploy and scale for applications in the cloud.

Simplicity

With minimal configuration and setup, KrakenDB is simple to administer and deploy making automated deployments with Puppet and Chef simple. Additionally, you can run it in a container as well.
