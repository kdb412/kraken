krakenDB Engine

Welcome to the krakenDB website. krakenDB is a self contained, single binary, open source, easily configured database engine.

Simplicity

krakenDB is easy to deploy and configure in the cloud or using container technologies such as Vagrant or Docker, to name a few. This is achieved by having default features and settings that support modern and highly available applications.

Speed/Scalability

Out of the box, krakenDB provides horizontal scaling, clustering as well as disaster recovery setups.

RDBMS

While krakenDB is simple to deploy and scale, it behaves like a relational database management system. krakenDB provides an SQL interface, user management, secure network communication, a storage engine as well as a daemon process to service your database requests.

Open source community

krakenDB is an open sourced technology; openly sharing and contributing to technology benefits everyone. The source code for krakenDB is available here.
